# Walkthrough: Xóa Bỏ Hoàn Toàn Hệ Thống Xác Thực Admin 2FA Bằng Mã & Email Cũ

## 1. Mục tiêu thực hiện
Loại bỏ triệt để tiến trình chạy ngầm gửi email 2FA và in mã bảo mật console:
```text
[ADMIN 2FA] ========================================
[ADMIN 2FA] MÃ BẢO MẬT HIỆN TẠI LÀ: xxxxxx
[ADMIN 2FA] Trạng thái gửi: SMTP chưa cấu hình/không khả dụng (Mã in tại Console)
[ADMIN 2FA] ========================================
```
Hệ thống hiện tại chuyển toàn bộ quyền truy cập Quản trị sang **Chế độ Nhà phát triển (Developer Mode)** với cơ chế bảo mật xác thực chuyên biệt.

## 2. Các tệp đã can thiệp & xóa bỏ

1. **Xóa tệp lập lịch phát mã ngầm**:
   - `backend/src/modules/admin/scheduler.py`: Đã xóa bỏ hoàn toàn tệp này cùng tệp bytecode trong `__pycache__`.
2. **Loại bỏ tiến trình khỏi máy chủ trung tâm**:
   - [server.py](file:///e:/Documents/Tử%20Vi%20Hồng%20Ân%20Website/backend/src/server.py): Xóa lệnh import `from modules.admin.scheduler import start_scheduler` và lệnh gọi hàm `start_scheduler()` khi server khởi động.
3. **Cập nhật Logic cơ sở dữ liệu**:
   - [admin_db.py](file:///e:/Documents/Tử%20Vi%20Hồng%20Ân%20Website/backend/src/modules/admin/admin_db.py): Xóa hai hàm `get_current_2fa_code()` và `save_2fa_code()`.
   - [db.py](file:///e:/Documents/Tử%20Vi%20Hồng%20Ân%20Website/backend/src/core/db.py): Xóa định nghĩa tạo bảng `admin_2fa_codes`.
   - Cơ sở dữ liệu SQLite `backend/src/data/tuvi.db`: Thực thi lệnh `DROP TABLE IF EXISTS admin_2fa_codes;`.
4. **Vô hiệu hóa endpoint đăng nhập 2FA cũ**:
   - [admin_auth.py](file:///e:/Documents/Tử%20Vi%20Hồng%20Ân%20Website/backend/src/modules/auth/admin_auth.py): Gỡ bỏ logic kiểm tra mã 2FA từ DB; trả về phản hồi mã HTTP `410 Gone` hướng dẫn sử dụng Developer Mode. Giữ nguyên tương thích cho các token session hiện có (`admin_` và `dev_`).
