## Tối Ưu Bảng Chọn Tab Điều Hướng Sang Dạng Hàng Ngang Trên Mobile (Lịch Vạn Sự)

### 1. Mục Tiêu
- Chuyển đổi khối bảng chọn tab điều hướng 3 chế độ xem (`Ngày`, `Tháng toàn cảnh`, `Ngày tốt`) trên giao diện thiết bị di động (mobile) từ dạng cột dọc xếp 3 tầng thành dạng **thanh hàng ngang phân đoạn (Segmented Horizontal Bar)**.

### 2. Các Thay Đổi Kỹ Thuật
- **Tệp chỉnh sửa**:
  - [`frontend/src/features/lich-van-su/LichVanSu.css`](file:///e:/Documents/Tử%20Vi%20Hồng%20Ân%20Website/frontend/src/features/lich-van-su/LichVanSu.css)
  - [`frontend/src/features/lunar-calendar/LichVanSu.css`](file:///e:/Documents/Tử%20Vi%20Hồng%20Ân%20Website/frontend/src/features/lunar-calendar/LichVanSu.css)
- **Chi tiết CSS**:
  - Tại media query `@media (max-width: 768px)`:
    - Áp dụng cấu trúc lưới 3 cột ngang cân xứng:
      ```css
      .lvs-vertical-nav {
        flex-direction: row !important;
        display: grid !important;
        grid-template-columns: repeat(3, 1fr) !important;
        padding: 6px !important;
        gap: 6px !important;
      }
      ```
    - Tinh chỉnh các nút `.v-nav-btn`: `padding: 10px 4px`, `font-size: 13px`, căn giữa `justify-content: center`, viền bo góc `rounded-lg (8px)` và không bị xuống dòng vụn (`white-space: nowrap`).
    - Tab được kích hoạt (active): nền hồng nhạt `#fdf2f2`, chữ đỏ chu sa `--primary-red`, gạch chân đáy `border-bottom: 3px solid var(--primary-red)`.
