## 1. Tóm Tắt Nhiệm Vụ & Yêu Cầu Cốt Lõi
Theo yêu cầu trực tiếp từ người dùng:
1. **Loại bỏ hoàn toàn hiệu ứng ánh sáng / hào quang (glow/aura)**: Xóa bỏ các thuộc tính đổ bóng mờ nhạt (`box-shadow: 0 0 14px...`, quầng bloom).
2. **Thiết lập đường viền có màu sáng nổi bật, nét dày hơn để che phủ hoàn toàn các phần viền đen**:
   - Sử dụng các mã màu có độ rực sáng và tương phản cao (Đỏ Son tươi, Cam Hoàng Kim sáng, Xanh Lục Bảo, Xanh Lam Hoàng Gia).
   - Nét dày dặn (3.5px – 4.5px solid), kết hợp cơ chế `box-shadow` hai chiều (outset phủ đè ra ngoài rãnh ranh giới đen + inset lấn vào trong) cùng thứ tự lớp `z-index: 25` để **che phủ tuyệt đối các đường viền đen 1px** giữa các cung và trung cung.
3. **Màu nền của tờ lá số phải trắng trơn hoàn toàn**:
   - Khôi phục 100% màu nền trắng tinh khiết (`#ffffff`) cho toàn bộ 12 cung và Thiên Bàn trung tâm.
   - Loại bỏ hoàn toàn hình ảnh mờ watermark logo (`.tb-watermark-bg { display: none !important; }`).
   - Xóa bỏ mọi vết phớt hồng (`#fff8f8`) hoặc xám ngả màu khi hover/active, đảm bảo tờ lá số luôn giữ độ phẳng và trắng trơn thanh tao.
4. **Kiểm tra và tinh chỉnh độ hoàn thiện của màn hình tải (Loading Screen)**:
   - Nâng cấp màn che mờ với nền trắng kính mờ (`rgba(255, 255, 255, 0.95)`, `backdrop-filter: blur(6px)`).
   - Thiết kế Thẻ Thiên Bàn An Sao (Celestial Loading Card) trang trọng với con quay kép Chu Sa - Hoàng Kim, vòng tinh tú đứt nét quay ngược chiều, tâm sao phát sáng `✦`.
   - Bổ sung thông điệp huyền học: *"Đang an sao lập thành lá số... • Khởi định Cục • Bố trí 12 Cung Chức"*.
   - Khắc phục lỗi DOM thẻ đóng thừa và nâng thời gian hiển thị đệm tối thiểu lên 350ms nhằm triệt tiêu hoàn toàn hiện tượng nhấp nháy (flicker).

## 2. Chi Tiết Các Thay Đổi Kỹ Thuật

### A. Hệ Thống Viền Sáng Nét Dày Che Phủ Viền Đen (`board.css`)
| Cung Số & Vai Trò | Mã Màu Sáng Nổi Bật | Cấu Trúc Viền Che Phủ Viền Đen (Solid) | Độ Dày Thực Tế | Chỉ Số Lớp (z-index) |
|---|---|---|---|---|
| **Bản Cung (Active)** | **Đỏ Son Tươi Sáng** (`#dc2626`) | `box-shadow: 0 0 0 2px #dc2626, inset 0 0 0 2.5px #dc2626 !important;` | **4.5px solid** | `z-index: 25 !important` |
| **Tam Hợp (Triad)** | **Cam Hoàng Kim Sáng** (`#ea580c`) | `box-shadow: 0 0 0 1.5px #ea580c, inset 0 0 0 2px #ea580c !important;` | **3.5px solid** | `z-index: 20 !important` |
| **Xung Chiếu (Opposite)** | **Xanh Lục Bảo Sáng** (`#16a34a`) | `box-shadow: 0 0 0 1.5px #16a34a, inset 0 0 0 2px #16a34a !important;` | **3.5px solid** | `z-index: 20 !important` |
| **Nhị Hợp (Harmonic)** | **Xanh Lam Hoàng Gia** (`#2563eb`) | `box-shadow: 0 0 0 1.5px #2563eb, inset 0 0 0 2px #2563eb !important;` | **3.5px solid** | `z-index: 20 !important` |
| **Rê Chuột (Hover)** | **Đỏ Nhạt Tương Phản** (`rgba(220, 38, 38, 0.45)`) | `box-shadow: 0 0 0 1px, inset 0 0 0 1.5px !important;` | **2.5px solid** | `z-index: 15 !important` |

- **Cơ chế che phủ viền đen tuyệt đối**: Lưới `.tuvi-board` có `gap: 1px` trên nền `#1c1917`. Khi cung active có `box-shadow: 0 0 0 2px ...` cùng `z-index: 25`, lớp viền ngoài 2px sẽ tràn qua 1px rãnh đen và vẽ đè lên trên, giúp triệt tiêu hoàn toàn viền đen tại 4 cạnh của cung đó.
- **Đồng bộ màu sắc nhãn & vector**:
  - Nhãn quan hệ: `.tag-active` (`#dc2626`), `.tag-triad` (`#ea580c`), `.tag-opposite` (`#16a34a`), `.tag-harmonic` (`#2563eb`).
  - Đường vector trung cung: Tam Hợp `stroke: #dc2626; stroke-width: 2.0;`, Xung Chiếu `stroke: #16a34a; stroke-width: 2.0;`, Nhị Hợp `stroke: #2563eb; stroke-width: 2.0;`.

### B. Màu Nền Trắng Trơn Hoàn Toàn (Pure Plain White)
- Ẩn hoàn toàn logo mờ: `.tb-watermark-bg { display: none !important; }`.
- Thiên Bàn `#thien-ban`: `background: #ffffff !important; box-shadow: none !important;`.
- Tất cả các cung `.house`, `.house.is-active-palace`, `.house:hover`: `background-color: #ffffff !important;`.
- Cung không liên quan: Giữ nguyên nền trắng 100% (`background-color: #ffffff !important; opacity: 1 !important;`), chỉ giảm độ đậm chữ (`.house:not(.is-related) > * { opacity: 0.35 !important; }`).

### C. Nâng Cấp Hoàn Thiện Màn Hình Tải (Loading Screen)
- **Cấu trúc HTML mới** (`laso-tuvi.html`, `laso-tuvi.bundle.html`):
  ```html
  <div id="tuviLoadingOverlay" class="tuvi-loading-overlay">
      <div class="tuvi-loading-card">
          <div class="tuvi-celestial-spinner">
              <div class="spinner-ring-outer"></div>
              <div class="spinner-ring-inner"></div>
              <div class="spinner-core">✦</div>
          </div>
          <div class="tuvi-loading-content">
              <div class="tuvi-loading-title">Đang an sao lập thành lá số...</div>
              <div class="tuvi-loading-sub">Khởi định Cục • Bố trí 12 Cung Chức</div>
          </div>
      </div>
  </div>
  ```
- **Sửa lỗi DOM**: Loại bỏ thẻ `</div>` đóng sớm làm rơi `.tuvi-board` ra ngoài `.tuvi-board-wrapper`.
- **Hiệu năng & Trải nghiệm** (`ui-controller.js`):
  - `MIN_LOADING_TIME = 350; // ms` giúp hiệu ứng chuyển cảnh mượt mà, mắt người kịp tiếp nhận và không bị giật nhấp nháy.
