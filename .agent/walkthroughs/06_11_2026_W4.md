## 1. Tóm Tắt Nhiệm Vụ & Mục Tiêu Thiết Kế
Thiết kế và triển khai hệ thống hiệu ứng thị giác tương tác cao cấp cho tờ lá số Tử Vi Đẩu Số:
- **Sáng viền sắc nét (Sharp Glowing Borders)**: Đường viền khép kín trọn vẹn cả 4 cạnh với độ tương phản cao, định vị dứt khoát ranh giới của từng cung khi được chọn hoặc liên kết quan hệ.
- **Tỏa sáng cực nhẹ (Subtle Aura / Bloom Glow)**: Quầng sáng hào quang mềm mại lan tỏa quanh ô cung với sắc độ vừa đủ, êm dịu thị giác, tạo chiều sâu không gian huyền học tĩnh tại mà không gây lóa mắt hay lòe loẹt.
- **Phân định màu trội độc lập (Dominant Role Colors)**: Từng vai trò cung (Bản Cung, Tam Hợp, Xung Chiếu, Nhị Hợp) sở hữu mã màu trội riêng biệt, đồng bộ từ viền, quầng hào quang, huy hiệu badge đến đường nối vector trung cung.
- **Bảo tồn tuyệt đối nền giấy trắng tinh khiết (`#ffffff`)**: Khắc phục triệt để hiện tượng các cung không liên quan bị xám xịt do màu nền khung bàn chiếu qua, chuyển sang cơ chế giữ nền trắng 100% và chỉ làm dịu nhẹ nội dung văn bản bên trong.

## 2. Thông Số Kỹ Thuật Hiệu Ứng & Bảng Màu Nhận Diện

### A. Bản Cung Đang Chọn (Active Palace)
- **Màu trội chủ đạo**: Đỏ Chu Sa Hoàng Triều (`#8b1d1d`).
- **Nền ô**: Hồng son phớt nhẹ (`#fff8f8`) tạo chiều sâu mỹ cảm.
- **Viền kép khép kín sắc sảo**: `inset 0 0 0 2px #8b1d1d`.
- **Ánh sáng hắt trong lòng cung**: `inset 0 0 16px rgba(139, 29, 29, 0.08)`.
- **Quầng hào quang tỏa sáng cực nhẹ bên ngoài**:
  `0 0 14px rgba(139, 29, 29, 0.35), 0 0 26px rgba(139, 29, 29, 0.16)`.
- **Lớp hiển thị**: `z-index: 10 !important;` (luôn nổi trên cùng, khép kín 4 cạnh, không bị ô liền kề đè cạnh).
- **Badge**: Màu đỏ son `#8b1d1d`, chữ "BẢN CUNG".

### B. Tam Hợp Cung (Triad Palaces)
- **Màu trội chủ đạo**: Nâu Son / Hoàng Thổ Trầm (`#9a3412`).
- **Nền ô**: Trắng tinh khiết (`#ffffff`).
- **Viền sắc nét**: `inset 0 0 0 1.5px #9a3412`.
- **Quầng hào quang tỏa nhẹ bên ngoài**:
  `0 0 12px rgba(154, 52, 18, 0.26), 0 0 22px rgba(154, 52, 18, 0.12)`.
- **Lớp hiển thị**: `z-index: 8 !important;`.
- **Badge**: Màu Nâu Son `#9a3412`, chữ "TAM HỢP".
- **Đường nối vector**: Tam giác nét đứt màu đỏ son `stroke: #8b1d1d; stroke-dasharray: 6 4;`.

### C. Xung Chiếu Cung (Opposite Palace)
- **Màu trội chủ đạo**: Xanh Trầm Bách / Trầm Mộc (`#15803d`).
- **Nền ô**: Trắng tinh khiết (`#ffffff`).
- **Viền sắc nét**: `inset 0 0 0 1.5px #15803d`.
- **Quầng hào quang tỏa nhẹ bên ngoài**:
  `0 0 12px rgba(21, 128, 61, 0.26), 0 0 22px rgba(21, 128, 61, 0.12)`.
- **Lớp hiển thị**: `z-index: 8 !important;`.
- **Badge**: Màu Xanh Trầm Bách `#15803d`, chữ "XUNG CHIẾU".
- **Đường nối vector**: Trục đối cung nét đứt xanh trầm `stroke: #15803d; stroke-dasharray: 6 4;`.

### D. Nhị Hợp Cung (Harmonic Palace)
- **Màu trội chủ đạo**: Chàm Cổ Thâm Uyên / Tím Than (`#4338ca`).
- **Nền ô**: Trắng tinh khiết (`#ffffff`).
- **Viền sắc nét**: `inset 0 0 0 1.5px #4338ca`.
- **Quầng hào quang tỏa nhẹ bên ngoài**:
  `0 0 12px rgba(67, 56, 202, 0.26), 0 0 22px rgba(67, 56, 202, 0.12)`.
- **Lớp hiển thị**: `z-index: 8 !important;`.
- **Badge**: Màu Chàm Cổ `#4338ca`, chữ "NHỊ HỢP".
- **Đường nối vector**: Trục nhị hợp nét đứt tím chàm `stroke: #4338ca; stroke-dasharray: 4 3;`.

### E. Cung Không Liên Đới (Unrelated Palaces)
- **Nền ô**: Bảo toàn 100% nền trắng tinh khiết (`background-color: #ffffff !important; opacity: 1 !important;`).
- **Nội dung bên trong**: Làm dịu nhẹ có chọn lọc (`.tuvi-board.has-active-focus .house:not(.is-related) > * { opacity: 0.35 !important; }`), giúp người dùng tập trung hoàn toàn vào Bản Cung và các cung đối/hợp mà không làm tối tờ lá số.

### F. Hiệu Ứng Rê Chuột (Hover State)
- `.house:hover`: `box-shadow: inset 0 0 0 1px rgba(139, 29, 29, 0.35), 0 0 8px rgba(139, 29, 29, 0.12); z-index: 5;`
- Chuyển động lướt êm dịu: `transition: background-color 0.2s cubic-bezier(0.22, 1, 0.36, 1), box-shadow 0.22s cubic-bezier(0.22, 1, 0.36, 1), opacity 0.2s ease;`.
