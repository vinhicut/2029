# Nhật Ký Thực Thi (Walkthrough) - 08/11/2026 (W17)

## Mục Tiêu Phiên Làm Việc
Cấu hình URL mặc định hiển thị, điều hướng và sao chép vào Clipboard trên script `deployment/scripts/start.py` cố định ở `http://127.0.0.1:5173`.

---

## 1. Chi Tiết Thay Đổi
Trong tệp [`deployment/scripts/start.py`](file:///e:/Documents/T%E1%BB%AD%20Vi%20H%E1%BB%93ng%20%C3%82n%20Website/deployment/scripts/start.py):
1. Đặt `local_dev_url = "http://127.0.0.1:5173"`.
2. Hàm `display_server_ip()` tự động sao chép `http://127.0.0.1:5173` vào Windows Clipboard (`clip`).
3. Trình duyệt tự động mở trực tiếp tại `http://127.0.0.1:5173`.
4. Bảng thông báo bảng điều khiển ưu tiên hiển thị dòng `Địa chỉ truy cập mặc định: http://127.0.0.1:5173`.

---

## 2. Kết Quả Kiểm Thử
- Máy chủ khởi động bình thường.
- `http://127.0.0.1:5173` phản hồi HTTP 200 OK.
- Liên kết trong Clipboard sẵn sàng dán ngay lập tức.
