## Mục Tiêu Phiên Làm Việc
Khắc phục lỗi `ImportError: cannot import name 'start_scheduler' from 'server'` khiến kịch bản `deployment/scripts/start.py` bị sập ngay khi vừa bật.

---

## 1. Nguyên Nhân Lỗi
- Trong tệp `deployment/scripts/start.py` (dòng 759), script import trực tiếp `from server import create_app, start_scheduler`.
- Trong khi đó, `backend/src/server.py` hiện tại không còn định nghĩa hàm `start_scheduler` độc lập ở cấp module, dẫn đến việc Python quăng ngoại lệ `ImportError` và dừng toàn bộ tiến trình khởi chạy trước khi kịp bật các máy chủ.

---

## 2. Giải Pháp Khắc Phục
- Trong [`deployment/scripts/start.py`](file:///e:/Documents/T%E1%BB%AD%20Vi%20H%E1%BB%93ng%20%C3%82n%20Website/deployment/scripts/start.py):
  - Chuyển sang import an toàn:
    ```python
    import server
    create_app = getattr(server, "create_app")
    start_scheduler = getattr(server, "start_scheduler", None)
    ```
  - Kiểm tra điều kiện `if callable(start_scheduler)` trước khi thực thi, đảm bảo tương thích ngược 100% dù backend có hay không có scheduler.
