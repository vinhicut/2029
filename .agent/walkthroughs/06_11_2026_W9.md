## Mục Tiêu Phiên Làm Việc
Nâng cấp tệp script Python hợp nhất `deployment/scripts/start.py`:
- Tự động kích hoạt đồng thời **5 tính năng cốt lõi** ngay khi bật script mà không cần hiển thị menu lựa chọn.
- Loại bỏ tính năng số 6 (Biên dịch Frontend `npm run build`) khỏi luồng khởi chạy để tối ưu hóa thời gian khởi động theo quy chuẩn của dự án.

## 1. Chi Tiết 5 Tính Năng Chạy Đồng Thời

Ngay khi khởi động (`python deployment/scripts/start.py` hoặc nhấp đúp `start.bat` / `start_lan.bat`), hệ thống tự động điều phối:

1. **[1] Khởi Chạy Cục Bộ (Local Dev)**:
   - Dọn dẹp các tiến trình chiếm dụng cổng 8080, 5173 và 8443.
   - Kiểm tra `node_modules` (tự động `npm install` nếu chưa có).
   - Khởi chạy Flask Core Engine trên cổng 8080 (`0.0.0.0`).
   - Khởi chạy Vite Dev Server trên cổng 5173 và tự động mở trình duyệt `http://localhost:5173`.
2. **[2] Máy Chủ Mạng Nội Bộ (LAN Server)**:
   - Tự động phát hiện IP LAN chính (`NetworkManager.get_primary_lan_ip()`).
   - Tạo hoặc tái sử dụng chứng chỉ SSL/TLS tự ký với đầy đủ Subject Alternative Names (SANs).
   - Khởi chạy song song máy chủ HTTPS bảo mật trên cổng 8443 phục vụ toàn bộ thiết bị trong mạng Wi-Fi.
3. **[3] Kết Nối Thiết Bị Android (ADB Reverse)**:
   - Luồng chạy nền tự động dò tìm `adb.exe`, quét thiết bị Android kết nối qua cáp USB.
   - Tự động ánh xạ ngược 3 cổng quan trọng (`5173`, `8080`, `8443`) sang thiết bị Android.
   - Gửi Intent mở trình duyệt Google Chrome trên điện thoại tới `http://localhost:5173`.
4. **[4] Phân Tích IP & Clipboard**:
   - Quét danh sách card mạng Wi-Fi/Ethernet.
   - Hiển thị bảng thông tin kết nối định dạng Unicode sang trọng.
   - Tự động sao chép (Copy) đường dẫn LAN vào Windows Clipboard (`clip`) để dán ngay.
5. **[5] Quản Lý Tường Lửa (Windows Defender Firewall)**:
   - Tự động kiểm tra và mở các cổng `8080,8443` trên Windows Defender Firewall nếu có quyền Admin, hoặc hướng dẫn câu lệnh tương ứng.

## 2. Danh Sách Tệp Đã Xử Lý
- `deployment/scripts/start.py`: Tái cấu trúc thành kiến trúc đồng thời (Multi-threaded & Subprocess orchestration), loại bỏ tính năng build số 6 và bỏ menu console.
- `deployment/scripts/start.bat`: Cập nhật gọi trực tiếp `start.py %*`.
- `deployment/scripts/start_lan.bat`: Cập nhật gọi trực tiếp `start.py %*`.

---

## 3. Cách Kiểm Tra & Vận Hành
```cmd
python deployment\scripts\start.py
```
Hoặc nhấp đúp chuột vào `start.bat` trên Windows. Hệ thống sẽ khởi chạy đồng thời toàn bộ 5 dịch vụ và sẵn sàng phục vụ.
